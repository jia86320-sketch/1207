计算的起源

01
Early Computing — 早期计算

核心要点

  • 计算机的本质是「处理信息」，人类几千年前就在做这件事——算盘、星图、历法都是计算
  • 最早的计算工具是算盘（Abacus），公元前2700年就有了
  • 1614年，John Napier 发明对数（Logarithms），把乘法变成加法，大大简化计算
  • 1822年，Charles Babbage 提出差分机（Difference Engine）：用齿轮做多项式运算
  • Babbage 后来设计了分析机（Analytical Engine）：包含内存、CPU、程序的完整概念，但没建成
  • Ada Lovelace 为分析机写了第一个算法，被认为是第一位程序员
  • 1890年美国人口普查用打孔卡片（Hollerith 的机器），后来成为 IBM 公司的基础

关键术语

Abacus 算盘 Difference Engine 差分机 Analytical Engine 分析机 Punch Card 打孔卡片 Ada Lovelace 第一位程序员
02
Electronic Computing — 电子计算

核心要点

  • 20世纪最大的计算需求来自军事：弹道计算表、密码破译
  • 1943年，Colossus（巨人计算机）在英国建成，用于破译德国 Lorenz 密码，是第一台可编程电子数字计算机
  • 1945年，ENIAC 在美国宾夕法尼亚大学建成，重30吨，用真空管（Vacuum Tubes）代替机械齿轮
  • Grace Hopper 发现了一只飞蛾卡在继电器里，创造了 "Bug" 和 "Debug" 这两个词
  • 1947年贝尔实验室发明晶体管（Transistor），取代真空管，体积更小、更可靠、更省电
  • 晶体管是所有现代电子设备的基础

关键术语

Vacuum Tube 真空管 ENIAC 第一台通用电子计算机 Transistor 晶体管 Grace Hopper Bug/Debug 词源

03
Boolean Logic & Logic Gates — 布尔逻辑与逻辑门

核心要点

  • George Boole 在1854年提出布尔代数（Boolean Algebra）：用 True/False 做逻辑运算
  • 三个基本操作：NOT（非）、AND（与）、OR（或）
  • 用晶体管可以实现这些逻辑操作 → 逻辑门（Logic Gate）
  • NOT门：一个晶体管，输入开 → 输出关，输入关 → 输出开
  • AND门：两个晶体管串联，都开才输出开
  • OR门：两个晶体管并联，任一开就输出开
  • 还有XOR（异或）：两个输入不同时才为 True，这个后面做加法器要用

关键术语

Boolean Algebra 布尔代数 NOT / AND / OR 基本逻辑门 XOR 异或门 Transistor 实现逻辑门的物理基础
04
Representing Numbers and Letters with Binary — 二进制表示数字和字母

核心要点

  • 计算机只用 0 和 1（开和关），所以用二进制（Binary）计数
  • 1个0或1叫 1 bit（比特），8个bit = 1 byte（字节）
  • 二进制每一位代表 2 的幂：1, 2, 4, 8, 16, 32, 64, 128
  • 1 byte 可以表示 0-255（256种状态）
  • 负数：用最高位当符号位（0正1负），或用补码
  • 小数：用浮点数（Floating Point），类似科学计数法
  • 文字：ASCII 编码（1963年），每个字母/符号对应一个数字。A=65, a=97, 0=48
  • ASCII 只有128个字符，后来扩展为 Unicode，支持全世界所有文字

关键术语

Binary 二进制 Bit / Byte 比特 / 字节 ASCII 美国信息交换标准代码 Unicode 统一编码 Floating Point 浮点数
05
How Computers Calculate — the ALU — 计算机如何计算：算术逻辑单元

核心要点

  • 计算机的核心运算部件叫 ALU（Arithmetic Logic Unit，算术逻辑单元）
  • ALU 由两部分组成：算术单元（做加减乘等数学运算）和逻辑单元（做 AND/OR/NOT 等逻辑判断）
  • 用 XOR 门 + AND 门可以做出半加器（Half Adder）：两个1位二进制相加
  • 两个半加器 + OR 门 = 全加器（Full Adder）：能处理进位
  • 把8个全加器连起来 = 8位加法器，可以做两个8位数的加法
  • ALU 还有溢出检测（Overflow）：结果超出位数范围时标记
  • ALU 用一个特殊的标志位（Flags）输出额外信息：Zero（结果是否为0）、Negative（是否为负）、Overflow（是否溢出）

关键术语

ALU 算术逻辑单元 Half Adder 半加器 Full Adder 全加器 Overflow 溢出 Flags 标志位
06
Registers and RAM — 寄存器和内存

核心要点

  • 计算机需要存储数据的地方，分两种：寄存器（少量、CPU内部）和 RAM（大量、独立芯片）
  • 存储的基本单元是锁存器（Latch）：能记住1位信息（0或1），用 OR 门 + 回路实现
  • 加上控制线 → 门控锁存器（Gated Latch）：可以控制何时写入
  • 把多个锁存器排成一行 = 寄存器（Register）：一次存一个完整的数（如8位寄存器存8位）
  • 大量锁存器用矩阵排列 + 地址线选择 = RAM（Random Access Memory）
  • RAM 是「易失性」的——断电就丢失数据
  • 16x16 的锁存器矩阵 = 256个地址，每个地址存1位，用8位地址线选择

关键术语

Latch 锁存器 Register 寄存器 RAM 随机存取存储器 Address 地址 Volatile 易失性
07
The Central Processing Unit (CPU) — 中央处理器

核心要点

  • CPU 是计算机的大脑，把 ALU + 寄存器 + 控制单元组合在一起
  • CPU 的工作循环（指令周期）： 取指（Fetch）→ 解码（Decode）→ 执行（Execute）
  • 取指：从内存（RAM）读取一条指令到CPU
  • 解码：指令用操作码（Opcode）指定做什么操作，后面可以跟操作数（数据地址）
  • 执行：控制单元根据操作码指挥 ALU 做运算，或读写内存
  • 有一个特殊的寄存器叫程序计数器（Program Counter），记录下一条指令的地址，每执行一条自动+1
  • 时钟（Clock）提供稳定节拍，CPU 速度用 Hz / GHz 衡量（每秒多少个周期）
  • 现代 CPU 有流水线（Pipelining）：同时处理多条指令的不同阶段

关键术语

CPU 中央处理器 Fetch-Decode-Execute 取指-解码-执行 Opcode 操作码 Program Counter 程序计数器 Clock Speed 时钟频率 Pipelining 流水线
08
Instructions & Programs — 指令与程序

核心要点

  • 指令集（Instruction Set）是CPU能理解的所有操作码列表
  • 常见指令类型： LOAD（从内存读数据到寄存器）、 STORE（把寄存器数据写入内存）、 ADD / SUB（加减运算）、 JUMP（跳转到另一个地址执行）
  • 条件跳转（JUMP IF）：根据标志位决定是否跳转 → 这是实现 if/else 和循环的基础
  • 把一系列指令排列好 = 程序
  • 程序和数据都存在同一个内存里（冯·诺依曼架构 Von Neumann Architecture）
  • Alan Turing 提出的 Turing Complete 概念：任何能做条件跳转和读写的设备，理论上可以计算任何可计算的问题

关键术语

Instruction Set 指令集 LOAD / STORE 读写内存 JUMP 跳转指令 Von Neumann Architecture 冯·诺依曼架构 Turing Complete 图灵完备
09
Advanced CPU Designs — 高级CPU设计

核心要点

  • 让CPU更快的方法不只是提高时钟频率，还可以并行处理
  • 流水线（Pipelining）：把指令分成几个阶段，不同指令的不同阶段同时进行（像工厂流水线）
  • 超标量架构（Superscalar）：CPU有多个ALU，同时执行多条指令
  • 多核（Multi-core）：一个芯片上有多个CPU核心，真正的并行
  • 分支预测（Branch Prediction）：CPU猜 if 条件会走哪个分支，提前执行。猜对了就快，猜错了要回滚
  • 乱序执行（Out-of-Order Execution）：不按程序顺序执行，而看哪条指令的数据准备好了就先执行
  • 现代CPU还有缓存（Cache）：L1/L2/L3 多级缓存，比 RAM 快得多

关键术语

Pipelining 流水线 Superscalar 超标量 Multi-core 多核 Branch Prediction 分支预测 Cache 缓存

Early Programming — 早期编程

核心要点

  • 最早的编程方式是打孔卡片：卡片上的孔代表指令和数据，机器读取孔的有无
  • Jacquard 织布机（1804年）用打孔卡片控制织布图案，是最早的"编程"概念
  • Herman Hollerith 的打孔卡片制表机用于1890年美国人口普查
  • 插线板（Plugboard）：通过插线来编程，ENIAC 就是这样工作的，换程序要重新接线
  • 冯·诺依曼架构的提出：把程序也存在内存里，不用每次重新接线
  • 程序从此可以像数据一样被修改——这是现代计算机的基础

关键术语

Punch Card 打孔卡片 Plugboard 插线板 Stored Program 存储程序
11
The First Programming Languages — 最早的编程语言

核心要点

  • 直接用二进制写指令 = 机器语言（Machine Language），对人类极不友好
  • 汇编语言（Assembly Language）：用简短的英文缩写代替二进制（如 ADD, MOV, JMP）
  • 汇编器（Assembler）把汇编代码翻译成机器语言
  • Grace Hopper 发明了第一个编译器（Compiler）：把更接近英语的代码翻译成机器语言
  • 编译型语言：先全部翻译成机器码再执行（如C语言）
  • 解释型语言：逐行翻译逐行执行（如Python）
  • 1957年 FORTRAN：第一个广泛使用的高级语言，用于科学计算
  • 1959年 COBOL：用于商业数据处理

关键术语

Machine Language 机器语言 Assembly 汇编语言 Compiler 编译器 FORTRAN / COBOL 早期高级语言

Programming Basics — Statements & Functions — 编程基础：语句与函数

核心要点

  • 语法（Syntax）：编程语言的语法规则，像英语的语法
  • 赋值语句（Assignment Statement）：把值赋给变量，如 a = 5
  • 控制流（Control Flow）：if/else 条件判断，for/while 循环
  • 函数（Function）：把一段代码打包，取个名字，可以反复调用
  • 函数的参数（Arguments）：输入给函数的数据
  • 函数的返回值（Return Value）：函数执行完输出的结果
  • 模块化编程（Modularity）：把大问题分解成小函数，降低复杂度
  • 好的函数应该是一个函数只做一件事

关键术语

Syntax 语法 Variable 变量 Function 函数 Control Flow 控制流 Modularity 模块化
13
Intro to Algorithms — 算法入门

核心要点

  • 算法（Algorithm）：解决问题的步骤，是精确而有限的指令序列
  • 同一个问题有多种算法，好坏差别巨大
  • 排序（Sorting）是经典算法问题：把一组数按大小排列
  • 冒泡排序（Bubble Sort）：相邻两个比较交换，简单但慢
  • 归并排序（Merge Sort）：分而治之，先拆再合，更快
  • 大O表示法（Big O Notation）：衡量算法效率，表示数据量增长时运算次数的增长趋势
  • O(n)：线性增长；O(n²)：平方增长（慢）；O(n log n)：归并排序的效率
  • 二分查找（Binary Search）：在有序数组中每次砍一半，O(log n)，非常快

关键术语

Algorithm 算法 Big O Notation 大O表示法 Bubble Sort 冒泡排序 Merge Sort 归并排序 Binary Search 二分查找
14
Data Structures — 数据结构

核心要点

  • 数据结构：组织和存储数据的方式，选对了结构算法才高效
  • 数组（Array）：连续存放，通过下标快速访问。缺点：插入/删除中间元素慢
  • 链表（Linked List）：每个元素存储下一个元素的地址，插入删除快，但访问要顺藤摸瓜
  • 栈（Stack）：后进先出（LIFO），像一摞盘子，最后放的最先拿
  • 队列（Queue）：先进先出（FIFO），像排队
  • 树（Tree）：有层级关系，根节点→子节点。二叉搜索树：左小右大，查找快
  • 图（Graph）：节点+边，表示网络关系（如社交网络、地图路线）

关键术语

Array 数组 Linked List 链表 Stack / Queue 栈 / 队列 Tree 树 Graph 图
15
Alan Turing — 艾伦·图灵

核心要点

  • Alan Turing（1912-1954）是计算机科学之父
  • 1936年提出图灵机（Turing Machine）：一个理论模型，一条无限纸带+读写头+状态表
  • 图灵机证明了：任何可计算的函数都可以用这台理论机器计算
  • 停机问题（Halting Problem）：图灵证明了不可能有一个通用算法判断任意程序是否会终止
  • 二战期间在布莱切利园破译德国 Enigma 密码，加速了战争结束
  • 1950年提出图灵测试（Turing Test）：如果人无法分辨对话者是人是机器，就认为机器有智能
  • Turing 因同性恋被英国政府迫害，41岁去世。2013年获得皇家赦免
  • 图灵奖（Turing Award）：计算机界的诺贝尔奖

关键术语

Turing Machine 图灵机 Halting Problem 停机问题 Enigma 恩尼格玛密码机 Turing Test 图灵测试
16
Software Engineering — 软件工程

核心要点

  • 程序变复杂后，一个人写不完了 → 需要软件工程的方法管理复杂度
  • 面向对象编程（OOP）：把数据和处理数据的方法打包成「对象」
  • OOP 三大特性：封装（隐藏内部细节）、继承（子类复用父类代码）、多态（同一接口不同实现）
  • 设计模式（Design Patterns）：总结出的常见问题解决方案模板
  • 版本控制（Version Control）：Git 等工具跟踪代码修改历史
  • 测试（Testing）：单元测试、集成测试，保证代码正确性
  • 敏捷开发（Agile）：快速迭代、持续反馈，不是一次性做完
  • 文档（Documentation）：写清楚代码在做什么，方便团队协作

关键术语

OOP 面向对象编程 Encapsulation 封装 Inheritance 继承 Agile 敏捷开发 Version Control 版本控制

Integrated Circuits & Moore's Law — 集成电路与摩尔定律

核心要点

  • 集成电路（Integrated Circuit, IC）：把多个晶体管做到一块芯片上
  • 1958年，Jack Kilby（TI）和 Robert Noyce（Fairchild）分别独立发明IC
  • 芯片用光刻（Photolithography）制造：用光在硅片上刻出电路图案
  • 摩尔定律（Moore's Law）：Gordon Moore 1965年观察到——芯片上的晶体管数量约每2年翻一倍
  • 摩尔定律不是物理定律，是行业观察和自我实现的预言
  • 晶体管越来越小 → 更快、更省电、更便宜
  • 但物理极限逼近：原子级别，量子效应出现，摩尔定律正在放缓
  • 现代芯片在指甲盖大小上集成数十亿个晶体管

关键术语

IC 集成电路 Photolithography 光刻 Moore's Law 摩尔定律 Silicon 硅
18
Operating Systems — 操作系统

核心要点

  • 操作系统（OS）：管理硬件资源、为程序提供运行环境的软件
  • 早期的计算机没有OS——程序员直接操作硬件
  • OS 让多个程序同时运行（多任务），每个程序以为自己独占整个机器
  • 进程（Process）：正在运行的程序实例，OS给它分配内存和CPU时间
  • 内存管理：OS给每个进程分配独立的内存空间，互不干扰
  • 虚拟内存（Virtual Memory）：内存不够时，把部分数据挪到硬盘上
  • 设备驱动（Device Driver）：OS通过驱动程序统一管理不同硬件
  • 常见OS：Windows、macOS、Linux、Android、iOS
  • Unix（1969年）影响深远，Linux 是开源版本

关键术语

OS 操作系统 Process 进程 Multi-tasking 多任务 Virtual Memory 虚拟内存 Device Driver 设备驱动 Unix / Linux
19
Memory & Storage — 内存与存储

核心要点

  • 存储分为易失性（断电丢数据）和非易失性（断电保留）
  • RAM：易失性，快但断电丢失 → 临时工作区
  • 硬盘（Hard Drive）：非易失性，磁性记录，容量大但慢
  • 固态硬盘（SSD）：用闪存，比机械硬盘快很多
  • 存储层次（Memory Hierarchy）： 寄存器（最快最小）→ L1/L2/L3 缓存 → RAM → 硬盘/SSD（最慢最大）
  • 越上层越快但容量越小、越贵；越下层越大但越慢
  • 好的程序会尽量利用缓存，减少访问慢速存储
  • 磁带（Tape）至今仍在使用：超低成本大容量归档

关键术语

RAM 内存 Hard Drive 硬盘 SSD 固态硬盘 Cache Hierarchy 缓存层次 Volatile / Non-volatile 易失/非易失

Files & File Systems — 文件与文件系统

核心要点

  • 文件（File）：把相关数据组织成一个有名字的整体，方便管理
  • 文件有不同格式：格式 = 数据的组织方式（如 .txt, .wav, .bmp）
  • 文件系统（File System）：OS管理文件的方式，决定数据怎么存在硬盘上
  • 底层把存储空间分成块（Block/Sector），文件存在多个块中
  • 目录（Directory/Folder）：层级结构组织文件，像树状图
  • 文件系统维护文件分配表：记录哪个文件存在哪些块里
  • 常见文件系统：NTFS（Windows）、ext4（Linux）、APFS（macOS）、FAT32（U盘）
  • 碎片（Fragmentation）：文件分散在不连续的块中，影响性能，需要整理

关键术语

File 文件 File System 文件系统 Block / Sector 块 / 扇区 Directory 目录 Fragmentation 碎片
21
Compression — 数据压缩

核心要点

  • 压缩：用更少的数据表示同样的信息，节省空间和传输时间
  • 无损压缩（Lossless）：解压后和原数据完全一样
  • 有损压缩（Lossy）：丢掉人感知不到的细节，解压后有损失（如JPEG图片、MP3音频）
  • 无损压缩原理举例：游程编码（Run-Length Encoding）——"AAAAABBB" → "5A3B"
  • 霍夫曼编码（Huffman Coding）：高频数据用短编码，低频用长编码
  • 字典编码（Dictionary Coding）：把重复的模式替换为短引用（如 LZW）
  • JPEG 图片压缩：把图片分成小块，丢弃高频颜色变化（人眼不太敏感的部分）
  • 压缩率与质量的权衡：压得越小，质量损失越大

关键术语

Lossless / Lossy 无损 / 有损 Run-Length Encoding 游程编码 Huffman Coding 霍夫曼编码 JPEG / MP3 有损压缩格式

Keyboards & Command Line Interfaces — 键盘与命令行

  • 常用命令：ls（列目录）、cd（切换目录）、mkdir（创建目录）、rm（删除）

Screens & 2D Graphics — 屏幕与2D图形

核心要点

  • 最早的输出设备是打印机（打孔卡片→文字打印），后来有了CRT显示器
  • 阴极射线管（CRT）：电子枪扫射荧光屏，逐行点亮像素
  • 屏幕由像素（Pixel）组成，每个像素有颜色
  • 颜色用 RGB（红绿蓝）三原色混合表示，每个颜色0-255
  • 位图（Bitmap）：逐像素存储图像信息，简单但文件大
  • 矢量图（Vector Graphics）：用数学公式描述图形（线、圆），放大不失真
  • 早期电脑用字符显示：屏幕只显示文字，用ASCII字模渲染
  • 帧缓冲（Frame Buffer）：内存中存一整屏的像素数据，显示器持续刷新

The Personal Computer Revolution — 个人电脑革命

  • 1968年，Douglas Engelbart 的 "所有演示之母"（The Mother of All Demos）： 首次展示了鼠标、超文本、视频会议等概念

3D Graphics — 3D图形

Computer Networks — 计算机网络

核心要点

  • 计算机网络：多台计算机连接起来，互相传输数据
  • 最早的网络是军事和学术用途：ARPANET（1969），美国国防部的项目
  • 连接方式： 局域网（LAN）覆盖小范围（如办公室）， 广域网（WAN）覆盖大范围（如跨城市）
  • 数据传输方式： 电路交换（电话式，独占线路）vs 分组交换（Packet Switching）（数据切小包，共享线路）
  • 分组交换更高效：多个通信共享同一条线路
  • 每个数据包有目标地址，路由器负责转发到正确方向
  • IP地址：每台电脑在网络上的唯一地址

The Internet — 互联网

核心要点

  • 互联网（Internet）：把全世界的网络连在一起的「网络的网络」
  • 互联网使用分层协议，每层负责不同的功能
  • IP协议（Internet Protocol）：负责数据包的寻址和路由
  • TCP协议（Transmission Control Protocol）：保证数据完整、按顺序到达
  • TCP 把大文件切小，编号，接收端重组。丢了就重传
  • DNS（Domain Name System）：把域名（如 google.com）翻译成IP地址
  • ISP（Internet Service Provider）：互联网服务提供商，连接你和互联网
  • 互联网没有中心控制——这是设计上的优点：健壮、抗毁

The World Wide Web — 万维网

核心要点

  • 万维网（WWW）≠ 互联网：互联网是基础设施，万维网是跑在互联网上的应用之一
  • 1989年，Tim Berners-Lee 在 CERN（欧洲核子研究中心）发明了WWW
  • 三个核心组件： URL（统一资源定位器，网址）、 HTTP（超文本传输协议，传输网页）、 HTML（超文本标记语言，描述网页内容）
  • 网页（Web Page）：用HTML写的文档，可以包含文字、图片、链接
  • 超链接（Hyperlink）：从一个网页跳到另一个——这是"网"的核心
  • 浏览器（Browser）：读取HTML并渲染成可视化网页的程序。第一个浏览器叫 WorldWideWeb
  • 1990年代初网页还是纯文本，后来有了图片、CSS样式、JavaScript交互
  • Web 的发展：Web 1.0（只读）→ Web 2.0（用户生成内容、社交）→ 移动互联网

Cybersecurity — 网络安全

核心要点

  • CIA三原则： Confidentiality（机密性，数据不被未授权的人看到）、 Integrity（完整性，数据不被篡改）、 Availability（可用性，服务不被中断）
  • 身份验证（Authentication）：证明你是谁。三种方式： 你知道什么（密码）、 你有什么（手机/密钥）、 你是什么（指纹/面容）
  • 双因素认证（2FA）：两种方式组合验证，更安全
  • 访问控制（Access Control）：决定了你能做什么、能看什么
  • 沙箱（Sandbox）：给程序一个隔离的运行环境，限制它能做的事
  • 安全是层层防御，没有单一银弹
  • 安全 weakest link 原则：系统安全性取决于最薄弱的环节

关键术语

CIA Triad 安全三原则 Authentication 身份验证 2FA 双因素认证 Access Control 访问控制 Sandbox 沙箱

Hackers & Cyber Attacks — 黑客与网络攻击

核心要点

  • 黑客原意是「精通技术的人」，现在多指未经授权入侵系统的人
  • 社会工程（Social Engineering）：骗人而非攻破技术。如钓鱼邮件假冒网站
  • 木马（Trojan）：伪装成正常程序的恶意软件
  • 病毒（Virus）：会自我复制，感染其他文件
  • 蠕虫（Worm）：不需要宿主，自动通过网络传播
  • 勒索软件（Ransomware）：加密你的文件，要求赎金
  • DDoS攻击：用大量请求淹没服务器，使其无法提供正常服务
  • SQL注入：在输入框中注入恶意SQL代码，骗取数据库数据
  • 零日漏洞（Zero-day）：软件厂商还不知道的漏洞，特别危险
  • 防御手段：杀毒软件、防火墙、入侵检测、保持更新

关键术语

Social Engineering 社会工程 Phishing 钓鱼 Trojan / Virus / Worm 木马/病毒/蠕虫 Ransomware 勒索软件 DDoS 分布式拒绝服务 Zero-day 零日漏洞
33
Cryptography — 密码学

核心要点

  • 密码学：把信息变成只有授权人能读懂的形式
  • 加密（Encryption）：明文 → 密文；解密（Decryption）：密文 → 明文
  • 对称加密：加密和解密用同一个密钥。快，但密钥怎么安全分享给对方是难题
  • 非对称加密（公钥加密）：用一对密钥——公钥（公开）和私钥（保密）
  • 用公钥加密 → 只有私钥能解密；用私钥签名 → 公钥可以验证
  • 解决了密钥分发问题，是互联网安全的基础
  • 数字签名：用私钥「签名」，任何人用公钥验证真伪
  • 哈希函数（Hash Function）：把任意数据变成固定长度的「指纹」。不可逆，用于验证数据完整性
  • 常见算法：AES（对称）、RSA（非对称）、SHA-256（哈希）

关键术语

Encryption / Decryption 加密 / 解密 Symmetric Key 对称密钥 Public / Private Key 公钥 / 私钥 Digital Signature 数字签名 Hash Function 哈希函数 AES / RSA 常见算法

Machine Learning & AI — 机器学习与人工智能

核心要点

  • 人工智能（AI）：让机器表现出类似人类的智能
  • 机器学习（ML）：AI的一个子领域，不从规则出发，而是从数据中学习规律
  • 监督学习（Supervised Learning）：给数据+标签，让模型学会输入→输出的映射。如：给一堆猫狗照片+标签，学会分类

  • 神经网络（Neural Network）：模仿大脑神经元的计算模型，多层网络可以学习复杂模式
  • 深度学习（Deep Learning）：多层神经网络，近年来大热
  • 训练数据越多，模型通常越好——数据是AI的「燃料」

Computer Vision — 计算机视觉

核心要点

  • 计算机视觉：让计算机「看懂」图片和视频内容
  • 难点：人类一眼看懂的图像，计算机看到的只是一堆数字（像素值）
  • 早期方法：边缘检测（Edge Detection）——找出像素值剧烈变化的地方

  • 现代方法：用卷积神经网络（CNN），自动学习图像特征

  • 训练方式：给大量标注图片，让模型学会区分不同类别
  • 挑战：光照变化、遮挡、角度、背景干扰
  • 人脸识别的伦理问题：隐私、监控、偏见

Natural Language Processing — 自然语言处理

核心要点

  • 难点：语言有歧义、有上下文、有隐喻，不是简单的规则可以覆盖
  • 语音识别（Speech Recognition）：把语音转成文字
  • 语法分析：理解句子结构（主语、谓语、宾语）
  • 语义分析：理解句子的含义
  • 早期方法：规则系统（写大量语法规则），太死板
  • 统计方法：用大量文本统计词的共现频率
  • 现代方法：大语言模型（LLM），用深度学习从海量文本中学习语言规律
  • 应用：翻译、语音助手、聊天机器人、自动写作

  • 未来的 通用机器人：能像人一样处理各种任务，目前还很远

Psychology of Computing — 计算心理学

核心要点

  • 计算机不只是技术问题，也是人的问题——界面怎么设计才能让人用得舒服
  • 人机交互（HCI, Human-Computer Interaction）：研究人和计算机之间的交互体验
  • 可用性（Usability）：产品好不好用、学习门槛高不高
  • 认知负荷：人脑同时处理信息的能力有限，界面越复杂越容易出错
  • 好的设计应该减少认知负担：直观、一致、给反馈
  • 设计原则：一致性（类似操作有类似效果）、反馈（操作后有回应）、可见性（选项都看得到）
  • 情感化设计：好的设计不只是好用，也让人愉悦
  • 技术最终是为人服务的，不是反过来

关键术语

Educational Technology — 教育技术

The Future of Computing — 计算的未来

核心要点

  • 回顾：从算盘到晶体管到集成电路到个人电脑到互联网到AI——计算机的发展越来越快
  • 当前趋势与未来方向：
  • 量子计算机（Quantum Computing）：利用量子叠加和纠缠，理论上可以同时探索大量可能性。适合特定问题（如密码破解、药物模拟），但还在实验阶段
  • 脑机接口（Brain-Computer Interface）：直接连接大脑和计算机，可能让瘫痪者控制设备，甚至扩展人类认知
  • 物联网（IoT）：万物互联——冰箱、汽车、灯泡都连上网
  • 边缘计算：在设备本地做计算，减少延迟，保护隐私
  • AI无处不在：AI将融入所有工具，像电力一样成为基础设施
  • 伦理与责任：技术越强大，越需要思考——隐私、公平、偏见、就业、自主性
  • 技术从来不是中立的——设计它的人决定了它的方向
  • Carrie Anne 的结语：理解计算机科学的人越多，未来越值得期待
